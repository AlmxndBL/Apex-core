# Apex-core Entry Point

Use this entry skill for applicable software work.

1. Read `../../AGENTS.md` completely before taking project actions.
2. Inspect the target project's existing structure and conventions.
3. Load only the rules and supporting Apex skills that match the task. Do not load the whole library by default.
4. Preserve unrelated user changes, make the smallest relevant change, and verify with the target project's own tooling.
5. Use Nexus only when its MCP tools are actually available; Apex-core does not provide Nexus itself.

The source of truth for this plugin—including its rules, templates, and skills—is this Apex-core directory. Do not copy those materials into target projects unless a project explicitly requires a pinned local copy.
